# Security Policy

## Supported Versions

Security fixes are applied to the latest commit on `main`.

## Reporting a Vulnerability

Use GitHub's private "Report a vulnerability" flow for security issues in this
repository. Do not open a public issue for an exploitable problem.

Include the affected Skill, reproduction steps using placeholders, expected
impact, and any suggested mitigation. Never include live VM Service tokens,
credentials, private application logs, database exports, or sensitive
screenshots.

## Scope

These tools are intended for local Flutter debug workflows. They do not
authorize remote debug endpoints, credential extraction, destructive data
operations, or other high-impact actions without explicit user approval.
